Blume Bridge moves tokens between the XRP Ledger and XRPL EVM. Its keys are held by a cluster of nodes on Evernode instead of a person: every node reads both chains on its own, they vote on what they saw, and nothing is signed until k of n agree.

It has run on mainnet since October 2026. The code, the contracts and the design are open, along with an honest list of what is not decentralized yet.
